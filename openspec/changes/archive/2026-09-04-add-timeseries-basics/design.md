# Design: add-timeseries-basics

## Context

`datalist_window.go` holds `Rolling` (snapshot of the source, `RollingOptions{Window, MinObs, Center, Weights}`, reducers over `windowBounds`/`collect`, `Corr(other)` with index alignment and truncation to the shorter series) and `Expanding`. Window semantics are pinned against pandas by `datalist_window_crosslang_test.go`, which reads `testdata/window_fixtures.json` generated by `testdata/gen_window_fixtures.py`. `datatable_groupby.go` defines `AggregateOp` (`OpSum … OpFirst, OpLast`) and `GroupBy(...).Aggregate`. Core methods report bad options through `dl.warn` and an empty result rather than an error, and `DataTable` methods that can fail return `error`. `mkt/time_scale.go` has a private `truncateTime` but `mkt` depends on the root, so the root cannot reuse it.

## Goals / Non-Goals

**Goals:**
- pandas-exact EWM mean/var/std, pinned by generated fixtures.
- Rolling covariance and beta with the same contract as `Corr`.
- Resample that produces finance-conventional bars with existing aggregate operators.

**Non-Goals:**
- EWM covariance/correlation, `Rolling.Cov` with `Weights`, time-aware (irregular-spacing) EWM.
- Resample with custom anchors, business-day calendars, intra-day frequencies, or upsampling/filling.
- CLI/DSL commands for these; a later change can expose them once the API has settled.

## Decisions

### EWM as its own builder type, not a `RollingOptions` flag

Exponential weighting has no window; putting `Alpha` on `RollingOptions` would make `Window` meaningless for that mode and `Weights` contradictory. `EWMDataList` mirrors `ExpandingDataList`: it snapshots the source, carries an error string for bad options, and its reducers run one forward pass. Exactly one of `Alpha`/`Span`/`HalfLife` is required — there is no sensible default decay and pandas refuses the same ambiguity.

### Adjust and Bias follow pandas literally

`Adjust: true` computes the weighted mean as `Σ w_i x_i / Σ w_i` with `w_i = (1−α)^{t−i}`; `Adjust: false` uses the recursion `y_t = (1−α) y_{t−1} + α x_t`. Variance uses pandas' online algorithm with the same weight sequence; `Bias: false` applies pandas' correction `Σw² / ((Σw)² − Σw²)`. Nil cells are skipped without resetting the accumulators (pandas `ignore_na=True` semantics are *not* used; pandas' default `ignore_na=False` keeps the weight decaying across the gap, and that is what the fixtures encode). The generator script gains `ewm_mean`/`ewm_var`/`ewm_std` cases so the corpus, not a hand derivation, is the reference.

### Rolling Cov and Beta reuse Corr's pairing loop

`Corr` already builds `xs, ys` per window; the pairing is factored into a private helper the three reducers share, so nil handling and truncation cannot diverge. `Cov` divides by `n−1` to match `stats.Covariance`; `Beta` is `Cov/Var(other)` with the same `n−1` so it equals `quant.Beta` on a full window. Zero benchmark variance yields nil, the same "undefined" convention `Corr` uses for a zero denominator.

### Resample builds on GroupBy rather than a new aggregation engine

Resample truncates the time column to a period key, groups by it, applies the caller's `AggregateOp`s through the existing `GroupBy` machinery, then relabels each key with the period's last calendar day and sorts ascending. Period labelling by end-of-period is the bar convention (a "monthly close" is dated month-end); start-of-period labels are what `GroupBy` on a truncated date would give and are the thing users have to fix by hand today. Weekly buckets are Monday–Sunday (ISO), labelled Sunday. Empty periods are not emitted because fabricating rows would require a fill policy the caller did not state.

### Errors versus warnings

`EWM` and `Rolling.Cov/Beta` follow the core window convention (warn, empty result) because they sit beside `Rolling`. `Resample` returns `error` because it sits beside `Merge` and `GroupBy…Aggregate`, which return errors for bad column references.

## Risks / Trade-offs

- [EWM variance drifts from pandas on nil-heavy input] → fixtures include nil-containing cases for every option combination; the crosslang test fails on any 1e-9 deviation.
- [Weekly label choice (Sunday) surprises users expecting Friday] → documented; the label is the calendar period end, not the last trading day, and the docs show how to take `OpLast` on the date column to get the last trading day instead.
- [`Resample` on a time column with mixed time zones] → the period key is computed in each value's own location; documented, and a test pins it.
- [Interface additions break external implementers of `IDataList`/`IDataTable`] → the project already extends these interfaces per feature (e.g. `Rolling`); noted in the changelog.
